# Snake Game

A small Java Swing snake game built for the Term 2 workspace.

## Controls

- `Space`: start game or toggle pause
- `P`: pause or resume
- `R`: restart
- Arrow keys or `W`, `A`, `S`, `D`: move the snake

## Run It

Compile and run from the `SnakeGame` folder:

```powershell
ant run
```

Or with the Java compiler directly:

```powershell
javac -d build\classes src\snakegame\*.java
java -cp build\classes snakegame.SnakeGame
```
